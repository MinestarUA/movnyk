# Мовник

Браузерний редактор для перекладу модифікацій Minecraft українською. Завантажуєте `.jar` мода або мовний `.json`, перекладаєте рядки з підказками, перевіркою якості й машинним перекладом, а далі експортуєте готовий ресурспак.

Працює повністю в браузері: сервера немає, файли й ключі API нікуди не надсилаються, крім обраного сервісу машинного перекладу.

**Відкрити:** https://minestarua.github.io/movnyk/

## Що вміє

- Бере мовні файли з `.jar` або окремий `.json`. Посібники Patchouli та GuideME з `.jar` перекладаються разом із мовними рядками.
- Імпортує наявні переклади з `.json`, `.lang`, `.zip` ресурспаку, `.jar` або буфера обміну, але лише ключі, що збігаються з проєктом.
- Відкрили нову версію мода, а переклади на місці: змінені рядки втрачають затвердження, перейменовані ключі розпізнаються за текстом.
- Підсвічує коди форматування (`§a`), плейсхолдери (`%s`, `{0}`) і розмітку модів (Patchouli, Create, Malum, Modonomicon, GuideME). Їх можна вставити в один клік, і машинний переклад їх не чіпає. Рядок показано так, як він виглядатиме в грі.
- Перевірка якості ловить пропущені токени, пробіли, розділові знаки, регістр, латинські літери в українських словах. Однозначні виправлення застосовуються одним натисканням.
- Машинний переклад через Google Gemini або DeepL для рядка чи всього проєкту.
- Пошук і заміна з регулярними виразами, фільтри неперекладених і незатверджених рядків, автопідказки слів із власних перекладів.
- Прогрес сесії автоматично зберігається в браузері; нещодавні проєкти відкриваються з головного екрана.
- Експорт ресурспаку з потрібним `pack_format` для обраної версії Minecraft.

Перелік комбінацій клавіш дивіться в редакторі, кнопка «Комбінації клавіш».

## Машинний переклад

Ключі вводите в «Налаштуваннях», вони зберігаються лише в `localStorage` браузера.

- Gemini: ключ з [Google AI Studio](https://aistudio.google.com/apikey), працює одразу.
- DeepL: ключ Free (`…:fx`) або Pro. API DeepL не дозволяє запити з браузера (CORS), тому потрібне розширення, що знімає це обмеження; посилання на нього є в налаштуваннях.

## Розробка

Потрібен [Bun](https://bun.sh).

```sh
bun install
bun run dev      # http://localhost:5173/movnyk/
bun run test     # Vitest
bun run lint     # ESLint
bun run build    # збірка в dist/
```

Стек: React, Vite, Tailwind CSS + daisyUI. Логіка без UI лежить у `src/lib/` і покрита тестами поруч (`*.test.js`); компоненти лежать у `src/components/`.

Розмітку конкретного мода додаєте як розширення синтаксису в `src/lib/syntaxExtensions/` (формат описано в `index.js`).

## Розгортання

Кожен push у `master` збирає й публікує сайт на GitHub Pages ([workflow](.github/workflows/deploy.yml)). Шлях `/movnyk/` задано в `vite.config.js` як `base`. Змініть його, якщо сайт переїде.
